## 二、购买前先确认：ECS 在不在你的可用品类里

1. 登录阿里云 → 右上角「费用」→ **费用与成本** → 左侧「卡券管理」→ **优惠券/代金券**
2. 找到这张云工开物券 → 点「**适用商品**」或「详情」
3. 在商品列表里搜 **云服务器 ECS**（顺带看 **轻量应用服务器** 在不在）

- **ECS 在列表**：按第三节买 ECS（推荐，规格选择多、券能全额抵扣的概率高）
- **只有轻量在列表**：那就买轻量应用服务器，同样跑 `deploy/setup-aliyun.sh`
- 两个都不在：看列表里哪个是"计算型"产品（如 函数计算 FC、容器服务 ACK），再来找我改方案

> 券的适用范围是"动态调整"的，官网页面只能看大类，**最准的是上面这个「适用商品」列表**。

## 三、下单参数（按这个填，目标是券全额抵扣、自付 0 元）

**入口**：阿里云官网 → 产品 → **云服务器 ECS** → 「立即购买」（**不要**从活动横幅进）

| 配置项 | 建议值 | 说明 |
|---|---|---|
| 付费模式 | **包年包月** | 按量付费虽支持，但演示期间常驻更省心 |
| 地域 | 华东1（杭州）/ 华东2（上海）/ 华北2（北京） | **必须国内节点**，否则券用不了 |
| 实例规格 | **ECS 经济型 e**：2核4G（推荐）或 2核2G | 前端构建 + Node + Docker，4G 更稳；2G 也能跑 |
| 镜像 | **Ubuntu 22.04** 或 Alibaba Cloud Linux 3 | 脚本两种都兼容 |
| 系统盘 | 40GiB ESSD Entry（默认即可） | 镜像+代码约 2~3G |
| 公网 IP | **勾选分配公网 IPv4** | 必须有，否则评委访问不到 |
| 带宽 | **固定带宽 3~5 Mbps** | 别选按流量；演示足够 |
| 购买时长 | **1~3 个月** | ⚠️ 关键：让**订单总价 ≤ ¥299.76**，券就能全额抵扣、实付 0 元。比赛也就几周，3 个月绰绰有余 |
| 安全组 | 放行 **22 / 80 / 443** | 购买后也还能改 |

**支付页**：在"优惠券/代金券"一栏勾选这张云工开物券 → 看**实付金额**是否变成 0（或几块钱）。
如果这里**找不到券可选**，说明该商品不在适用范围 → 换个规格/时长，或换轻量应用服务器再试。

## 四、部署（买完 5 分钟搞定）

### 1. 控制台放行端口
ECS 实例 → **安全组** → 配置规则 → 入方向添加：22（SSH）、80（HTTP）、443（HTTPS 备用）。

### 2. SSH 登录并一键部署
```bash
ssh root@你的公网IP

# 下载并执行部署脚本
curl -O https://raw.githubusercontent.com/Licktlove/GodView/main/deploy/setup-aliyun.sh
chmod +x setup-aliyun.sh
./setup-aliyun.sh
```
脚本会：装 Docker（配阿里云镜像加速）→ 拉代码 → 生成 `backend/.env`（**会提示你填 LLM_API_KEY**）→ `docker compose up -d --build` → 配 Nginx（SSE 免缓冲）。

### 3. 验证
```bash
curl http://127.0.0.1/api/health
# 期望：{"ok":true,"model":"qwen3.6-flash","keyConfigured":true,...}
```
浏览器打开 **`http://你的公网IP`** → 首页 → 进工作台 → **加载示例** → 看到 14+ 实体的图谱 → 再试生成世界 / 访谈 / 报告。

## 五、关于域名和 HTTPS（可选）

- **裸 IP 能直接访问**，比赛演示够用，报名表就填 `http://公网IP`。
- 要域名：万网买（⚠️ **域名不能用这张券**）→ 解析到 ECS → **必须备案**（境内节点，一般 5~15 个工作日）。
- 备案完成后再上 HTTPS（阿里云免费证书 + Nginx 配 443）。

时间紧就**直接用 IP**，别在备案上卡住。

## 六、踩坑速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 支付页找不到券 | 该商品/规格不在适用范围，或是活动折扣价 | 换标准购买页；换规格或时长；换轻量应用服务器 |
| 券只抵了一部分 | 订单总价 > 券余额 | 缩短购买时长，或补齐差额 |
| 访谈/报告"卡住半天才出字" | Nginx 缓冲了 SSE 流 | 确认用了 `deploy/nginx-godview.conf`（含 `proxy_buffering off`） |
| 页面能开但生成世界失败 | `LLM_API_KEY` 没填 / ai-router 拒了出口 IP | 检查 `backend/.env`；找 ai-router 管理员加出口 IP 白名单 |
| 外网打不开 | 安全组没放行 80 | 控制台安全组加入方向 80 |
