01 / SYSTEM WORKFLOW

从一个经营问题，走到一条可解释的行动链。

四个阶段不是四个孤立页面，而是一条从假设到决策的连续证据链。图谱在过程中持续生长，结果也可以回看和对比。

01DEFINE

WHAT IF · 构建世界

输入经营场景与假设事件，LLM 直接抽取实体和初始关系，建立一张可运行的零售世界。

场景 → 实体 → 关系
02GROW

SIMULATE · 自生长推演

图谱节点作为带人格的 agent 并行反应，新的动作、关系和世界事件在轮次中持续涌现。

动作 → 关系 → 生长
03REASON

OBSERVE · 决策报告

生成报告前先检索图谱证据，整理影响中心、演化趋势、冲突与因果链，再形成行动建议。

证据 → 因果 → 建议
04ASK

INTERVIEW · 随时问节点

点任意节点，用它的 persona 与推演记忆回答问题，也可以把局部答案放回全局决策语境。

节点 → 对话 → 追问
02 / CORE CAPABILITIES

不是聊天框，
是一张会动的经营地图。

GodView 把大模型的生成能力放进可观察的系统里：有图谱、有过程、有证据，也有能被业务人员继续追问的上下文。

01

LLM 直抽图谱

从种子文本直接抽取实体与初始关系，轻量启动，不依赖外部图数据库。

02

多智能体社会涌现

节点即 agent，按图谱上下文和世界事件并行反应，关键角色可锁定。

03

实时活动流

每轮动作、新关系和影响过程实时可见，推演不再是等待黑盒结果。

04

因果证据可追溯

报告动笔前先检索影响力中心、演化趋势和冲突，建议对应证据路径。

05

节点角色访谈

采访价格敏感型顾客、隔壁竞品或门店本身，理解它们为什么这么行动。

06

场景包可扩展

零售、供应链等领域知识外置为场景包，换场景不换推理引擎。
